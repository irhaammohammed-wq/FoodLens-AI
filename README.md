🍽️ FoodLens AI

See it. Know it. Cook it.

FoodLens AI is an AI-powered food image recognition and recipe recommendation application built with Streamlit. Upload a food photo, let a trained Food-101 ResNet-50 model identify the dish, explore matching recipes, and chat with AI Chef for personalized cooking guidance.

✨ Features

🧠 Food Image Recognition

Upload a food image directly in the app.

Uses a ResNet-50 model trained for Food-101 classification.

Displays the predicted food and confidence level.

Handles high-, medium-, and low-confidence predictions with appropriate messaging.

🍳 Recipe Recommendations

Matches the recognized food with recipes stored in recipes/recipes.json.

Displays recipe information such as ingredients, instructions, servings, calories, protein, carbohydrates, and fat when available.

Provides recipe guidance based on the model's prediction.

👨‍🍳 AI Chef

Powered by Google's Gemini API.

Ask questions about the detected food, recipe, ingredients, substitutions, cooking methods, and preparation.

AI Chef can use the currently selected recipe and food prediction as context.

Includes a conversational chat experience with chat history during the current session.

🎨 Modern Dashboard

Clean, responsive Streamlit interface.

Food upload and prediction workflow.

Recipe discovery section.

Dedicated AI Chef experience.

No login or signup required.

🛠️ Tech Stack

Python

Streamlit — web application interface

PyTorch — deep-learning inference

Torchvision — ResNet-50 model and image transforms

Pillow — image processing

Google GenAI SDK — Gemini-powered AI Chef

Food-101 — food image classification dataset/model basis

JSON — recipe data storage

🚀 Run Locally

1. Clone the repository

git clone https://github.com/irhaammohammed-wq/FoodLens-AI.git
cd FoodLens-AI

2. Create a virtual environment

Windows PowerShell:

python -m venv .venv
.\.venv\Scripts\Activate.ps1

macOS/Linux:

python3 -m venv .venv
source .venv/bin/activate

3. Install dependencies

pip install -r requirements.txt

4. Configure the Gemini API key

Create:

.streamlit/secrets.toml

Add:

GEMINI_API_KEY = "your-gemini-api-key"

Never commit secrets.toml or expose your API key publicly. It is excluded by .gitignore.

5. Run FoodLens AI

streamlit run app.py

Streamlit will provide a local URL, normally:

http://localhost:8501

☁️ Streamlit Cloud Deployment

Push the project to GitHub.

Open Streamlit Community Cloud.

Create a new app from the FoodLens-AI repository.

Select the main branch.

Set the main file to:

app.py

Add the following secret in the Streamlit Cloud app settings:

GEMINI_API_KEY = "your-gemini-api-key"

Deploy the app.

The model and recipe files must also be present in the GitHub repository at the paths expected by app.py:

models/food101_resnet50.pth
recipes/recipes.json

🔐 Security

FoodLens AI does not require user authentication in the current version.

The Gemini API key is required for AI Chef and should be stored only in Streamlit secrets. Do not place API keys directly inside app.py, README.md, or any committed source file.

⚠️ Important Notes

Food recognition is a machine-learning prediction and may not always be correct.

A lower-confidence prediction should be treated as a possible match rather than a guaranteed identification.

Recipe recommendations depend on the recipe data available in recipes/recipes.json.

AI Chef responses are generated by an AI model and should be checked against reliable cooking and food-safety guidance when appropriate.
